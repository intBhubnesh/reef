# Reef Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS notch app that shows live Claude Code and Codex sessions, lets the user approve, deny and answer agent requests from the notch, reveals completions, and jumps to the session's terminal.

**Architecture:** Agent hooks run `~/.reef/bin/reef-bridge`, which enriches the hook's stdin JSON and sends it as one JSON line over a Unix socket to the app; blocking requests hold the socket open until the UI (or focus change, or timeout) answers. `ReefCore` is a pure, AppKit-free library (models, reducer, protocol, decisions, diff, hook-config transforms, notch state machine, geometry, jump planning) with all the tests; `ReefBridge` and `ReefApp` are thin executables over it.

**Tech Stack:** Swift 6.2 toolchain in Swift 5 language mode (`swiftLanguageVersions: [.v5]`), SwiftPM only, macOS 14 deployment target, AppKit + SwiftUI, Foundation `JSONSerialization`/`Codable`, POSIX sockets, `AttributedString(markdown:)`, no third-party packages. Ad hoc code signing via `scripts/bundle.sh`.

**Spec:** `docs/superpowers/specs/2026-10-28-reef-design.md`

## Global Constraints

- macOS 14.0+, universal binary (`arch -arm64` and `x86_64` via `swift build --arch`), Swift Package only, no third-party dependencies.
- Bundle id `app.reef.macos`, `LSUIElement = true`, usage string `NSAppleEventsUsageDescription`, entitlement `com.apple.security.automation.apple-events`, `CODE_SIGN_IDENTITY` is one variable in `scripts/bundle.sh` defaulting to `-` (ad hoc).
- Paths: `~/.reef/bin/reef-bridge`, `~/.reef/run/reef.sock` (mode 0600), `~/.reef/cache/`, `~/Library/Application Support/Reef/settings.json` and `session-terminals.json`, `~/Library/Logs/Reef/reef.log` (JSON lines, keys `t,l,c,m,d`).
- Hook command string (exact): `/bin/sh -c '[ -x "$HOME/.reef/bin/reef-bridge" ] && "$HOME/.reef/bin/reef-bridge" --source claude; exit 0'` (`codex` for Codex). Timeouts: `PermissionRequest` 3600, all others 5; Codex `SessionEnd`/`Interrupt` 1.
- Bridge: exit code always 0; stdout `{}` for every non-blocking event and for any failure; blocking wait cap 3600 s; non-blocking socket send cap 2 s.
- Socket framing: one JSON object per line, UTF-8, `\n` terminated. Request `{"v":1,"id":"<uuid>","mode":"fire"|"wait","event":{...}}`, response `{"v":1,"id":"<same>","reply":{...}}`.
- Timing defaults: hover expand delay 0.15 s, reveal dwell 5 s, mouse-leave collapse 1 s, idle session cleanup 2 h, focus-release latency ≤ 200 ms.
- Island: collapsed = notch width + 32 pt each side, height = `safeAreaInsets.top`, bottom corner radius 16; expanded panel ≤ 648 × 580 pt, corner radius 24, black.
- Never ship Vibe Island assets. Never write permission rules to any `.claude/settings*.json`.

## Review Focus

1. Hook stdin that is not valid JSON, empty, or a JSON array: the bridge must print `{}` and exit 0 (Task 8).
2. A `wait` request whose socket closes before the UI answers (user quit the app, or the request was resolved in the terminal): the pending table must drop it and the UI card must disappear (Task 9).
3. Two sessions with the same `session_id` from different sources (`claude` and `codex`): they must be distinct sessions, keyed by `(source, session_id)` (Task 4).
4. `AskUserQuestion` input with `multiSelect: true` and the user choosing zero options: Submit must be disabled; with two options chosen the answer joins labels with `", "` (Task 3 and Task 11).
5. A screen without a notch (external display as main): geometry must fall back to a synthetic 185 × 33 island, never a zero-width pill (Task 10).
